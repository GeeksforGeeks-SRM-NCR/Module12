📡 Delay-Tolerant Networking (DTN)

Solving network problems in rural regions through store-and-forward messaging

Rural Network Challenges

  • Intermittent connectivity — Power cuts, weak signal, infrastructure gaps
  • Long delays — Satellite links, high-latency backhauls
  • Opportunistic links — Bus with WiFi, mobile data collector visiting villages
  • No end-to-end path — Source and destination never connected at the same time

Traditional vs DTN Approach

❌ Traditional TCP/IP

Requires continuous end-to-end connection. If the link drops, the message is lost. Rural users often cannot send data when connectivity is absent.

✅ DTN (Store-and-Forward)

Messages are stored locally when the link is down. When connectivity appears (e.g., relay passes by), stored bundles are forwarded. No data loss; delivery is eventual.

Use Cases in Rural Regions

  • Healthcare — Patient records, lab results, telemedicine requests forwarded when connectivity is available
  • Agriculture — Market prices, weather alerts, advisory messages
  • Education — Offline learning content synced when a relay visits
  • Emergency — Alerts stored locally and propagated through intermittent links
